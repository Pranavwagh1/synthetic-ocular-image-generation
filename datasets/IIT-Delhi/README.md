# IIT Delhi Iris Dataset

## Overview

The IIT Delhi Iris Dataset is one of the ocular datasets considered in this project for image analysis, preprocessing, quality assessment, and subsequent experiments involving diffusion models and ocular recognition.

The dataset contains iris images collected from different subject identities and can be used for iris recognition and biometric research, subject to the dataset's access and usage conditions.

## Dataset Structure

The dataset contains iris images organized by subject identity. The exact directory structure and file organization may vary depending on the version of the dataset obtained.

Example structure:

```text
IIT-Delhi/
├── subject_1/
│   ├── image_1
│   ├── image_2
│   └── ...
├── subject_2/
│   ├── image_1
│   ├── image_2
│   └── ...
└── ...
```

## Usage in This Project

The dataset is intended for use in the following experimental stages, where applicable:

- Dataset collection and analysis
- Image preprocessing
- Ocular image quality assessment
- Baseline iris recognition
- Synthetic image generation using diffusion models
- Dataset augmentation and recognition evaluation
- Comparison of image generation approaches
